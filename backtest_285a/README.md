# 285A.T デイトレカード・バックテスト

キオクシアHD (285A.T) のデイトレ「カード」ルールを過去データで再生シミュレーションし、
発動率・勝率・RR・期待値の実測、パラメータ最適域、情報タイミング感度を定量化する一式。

## 実行方法(1コマンド)

```bash
cd backtest_285a
./run_all.sh              # 実データ取得(Yahoo Chart API)→ バックテスト → レポート
./run_all.sh --offline    # 既存キャッシュ(data_raw/)のみで再実行
./run_all.sh --synthetic  # 合成データで動作検証(出力に SYNTHETIC 注記)
python3 -m unittest discover tests   # スモークテスト
```

依存: **Python 3.10+ 標準ライブラリのみ**(pandas等不要)。

> ⚠️ **本リポジトリに同梱の `output_sample/` は合成データによるフォーマット見本です。**
> 実相場の成績ではありません。構築時の実行環境は外部金融APIへの egress が
> ネットワークポリシーで遮断されていたため(query1/query2.finance.yahoo.com への
> CONNECT が403)、実データ取得はネットワークが通る環境で `./run_all.sh` を
> 実行してください。取得データは `data_raw/` にキャッシュされ、以後 `--offline` で
> 何度でも再集計できます。

## 出力物

| ファイル | 内容 |
|---|---|
| `output/results.csv` | 日付×カード×(発動有無/約定価格/出口/損益/MAE/MFE/引け滑り) |
| `output/daily_replay/{date}.md` | 朝8:55スナップショット・生成カード・執行ログ(検証可能な形) |
| `output/report.md` | 発動率/勝率/RR/期待値(OOS・レジーム別・イベント層別・カード型別)、パラメータ感度表、情報タイミング感度表、変更提案上位5(n数・改善幅つき) |

## 構成

```
config.py      … 全パラメータ・イベントカレンダー・レジーム定義
yahoo_fetch.py … Yahoo v8 chart API 取得+キャッシュ(User-Agent必須対応)
jpx_limits.py  … JPX 値幅制限表(基準値段=前日終値で日次計算)
data_model.py  … バー正規化(JST)・ポイントインタイム(PIT)アクセス
levels.py      … 座標エンジン: 前日高安/5日高安/未埋め窓/しこり帯(価格帯別出来高)/MA/丸数字/ADR理論値/NIY
cards.py       … カード生成 A押し目買い/B戻り売り/C深部受け/D突破 + 丸数字損切り回避
engine.py      … 場中5分足リプレイ: 指値約定・寄りバー約定禁止・OCO損切り優先・時間規制・韓国リスクオフ
backtest.py    … walk-forward(前半IS探索/後半OOS)・感度グリッド・レジーム/イベント層別
report.py      … results.csv / daily_replay / report.md 生成
synth.py       … 合成データ生成(スモークテスト専用・SYNTHETIC明記)
```

## 絶対原則の実装

- **ルックアヘッド禁止**: スナップショットは前日以前の日足+前日以前のセッションの5分足のみ。
  場中判定は当日5分足を時系列順に1本ずつ処理し、状態更新(減衰・バースト検出)は
  バー確定後にのみ次バー以降の判定に反映。USDJPY/NIYは8:55以前に確定したバーのみ。
- **執行規約**: 指値は「バー安値<指値」(買)/「バー高値>指値」(売)で約定。
  寄りバー(9:00-9:05)約定禁止。成行・逆指値はスリッページ1tick(10円)不利適用。
  OCO同バー両到達は損切り優先(保守)。
- **過学習ガード**: 営業日の前半でグリッド探索→後半OOS検証。全結果にn数併記、
  n<10は「参考」表記。
- **引けオークション**: 5分足は引けオークション非捕捉のため、
  日足公式終値−最終5分バー終値を「引け滑り」として全日記録・レポート掲載。
- **除外情報**: 引け残り板・PTS・群衆情報は過去再現不能のため不使用(レポートに明記)。

## モデリング上の選択(コード化にあたり定義を補ったもの)

仕様で厳密に定義されていない箇所は以下の通り実装した(全て `config.py` で調整可能):

- 同時保有は1枚まで(1日2枚は「2エントリー」として実装)
- C/D型の成行エントリーはシグナルバー終値+1tick(次バー寄り相当)で近似
- 利確目標: 損切り幅×2.0、ただし直近の抵抗/支持レベル手前(バッファ10円)を優先
- ADRアンカーON時: 予測ギャップ(理論値−前日終値)×0.5をカード座標にシフト、1%未満は無視
- 韓国リスクオフ: 000660.KS が寄り比 −2% 到達で当日新規エントリー停止
  (リアルタイム/20分遅延/不使用の3モードで感度計測)
- しこり帯: 過去20営業日の5分足を典型価格×出来高で25円ビンに集計、隣接ビンをマージした上位3帯
