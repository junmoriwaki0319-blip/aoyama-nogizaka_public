# 条件リスト銘柄 エントリー条件・撤退ライン再設計エンジン

対象: テクニスコ(2962) / 立花エレテック(8159) / 東光高岳(6617) / プロシップ(3763) / 扶桑化学工業(4368)

## これは何か

投資フレーム（4ゲート判定＋リスク管理制約）を、裁量が入らない形でコードに落としたもの。
実データを与えると、エントリーレンジ・株数・撤退ライン・想定最大損失・見送り条件・
距離順の一覧表までが一意に決まる。

設計順序は **構造 → 撤退ライン → サイズ** で固定してある。
サイズを先に決めて撤退ラインを後から動かす経路はコード上に存在しない。

## 実装済みの制約

| 制約 | 実装 |
|---|---|
| 1銘柄あたり最大損失45万円以内 | `shares = floor(450000 ÷ (最悪エントリー − 撤退ライン))` を単元切り捨て |
| 撤退ラインは支持帯の外側。同値・内側は禁止 | `stop = 支持帯下限 − 0.35×ATR14`、同値になる場合は強制的に1円下へ |
| 撤退ラインまでの距離は ATR14 の 1.5〜2.0倍 | レンジ上限・下限の両方で倍率を算出し、近すぎ／遠すぎを警告出力 |
| 買い指値は必ず撤退ラインより上 | `entry_low <= stop` なら「設計不能」を返して打ち切る |
| 急騰追いの禁止 | `no_chase: true` の銘柄はエントリー上限を現値未満に強制 |
| 薄い銘柄のサイズ上限 | 20日平均出来高の5%を株数の絶対上限 |
| 決算2週間前までに判断 | 次回決算日から14日前を判断期限として算出 |

ナンピン（取得単価割れの買い増し）は設計対象外なので、そもそも出力しない。

## 使い方

```bash
pip install --break-system-packages requests pdfplumber

python3 scripts/stock-design/designer.py              # 全銘柄
python3 scripts/stock-design/designer.py 8159 4368    # 銘柄指定
python3 scripts/stock-design/designer.py --json       # output.json も出力
```

`config.json` の `names[]` に人手入力（終値・既知の支持帯・次回決算日・急騰追い禁止フラグ等）、
`framework` に固定パラメータが入っている。銘柄の追加はここに1エントリ足すだけ。

## ネットワーク要件

以下へ到達できる環境で実行すること。iPhone の User-Agent 固定、0.4秒 sleep でレート制限を回避する。

- `query2.finance.yahoo.com` — 日足OHLCV（分割はadjcloseの比率で調整）
- `finance.yahoo.co.jp/quote/{CODE}.T/margin` — 信用残（週次）
- `webapi.yanoshin.jp` — TDnet開示一覧
- `tdnet-pdf.kabutan.jp` → 失敗時 `release.tdnet.info` — 短信PDF

## 検証状況

- 合成データ390パターン（39シード × 5価格帯 × 急騰追い禁止の有無）で不変条件を検証。違反0件
  - 撤退ラインが支持帯の外側にあること
  - 買い指値が撤退ラインより上にあること
  - 想定最大損失が45万円を超えないこと
  - 株数が単元(100株)の倍数であること
  - 急騰追い禁止銘柄でエントリー上限が現値未満であること
  - 株数が20日平均出来高の5%を超えないこと

## 注意

短信からの数値抽出は候補抽出であり、`evidence` に原文行を必ず添えて返す。
業績数値は原文行と突き合わせて確認すること。取得できなかった項目は `未取得` を伝播させ、
推定値では埋めない。
