## 主要事実

- **3D 保有比率推移**: 5.47% (2025-04) → 15.40% → **16.48%** (2025-12-24) → 17.5% (2026-02)
- 大株主順位: 創業者 福嶋康博 19.28% に対し 3D が第2位
- 3D 主張: 
  - 売上成長率低迷
  - 利益率低迷、ゲーム開発資産の大型減損
  - 家庭用/モバイル不振
  - アーケード・出版の非シナジー指摘
  - SQEX中計を「不十分かつ曖昧」と批判
  - CEO 短文回答 (詳細な反論なし) を公開
- プレゼン構成: スライド1〜93 = 2025-09-29 SQEX 提示の「外部から見た貴社の経営課題」、94〜 = 企業価値向上策の部分抽出
