# 商社セクター・ダッシュボード — フェーズ1 データ準備

本ディレクトリは商社セクター・ダッシュボード（v0.2 設計準拠）の **データ準備フェーズ** の成果物。HTML 実装 / ナビ追加 / sitemap 更新は別ブランチで行う。

## スコープ

- **Tier 1（本ブランチで対応）**: 5大商社 + 準大手2社 = 計7社
  - 三菱商事 (8058), 三井物産 (8031), 伊藤忠商事 (8001), 住友商事 (8053), 丸紅 (8002)
  - 双日 (2768), 豊田通商 (8015)
- **Tier 2（スコープ外）**: 専門商社・半導体商社 → フェーズ2「専門商社ダッシュボード」で別建て
- ユニ・チャーム (8113) は消費財メーカーのため除外

## ディレクトリ構成

```
data/sogo-shosha/
├── README.md                     ← 本ファイル
├── known-issues.md               ← 取得不能/推計に切り替えた KPI の一覧
├── comparison-matrix.md          ← comparison-matrix.csv のマークダウン版
├── raw/                          ← 各社の生データ (Yahoo Finance + EDINET キャッシュ)
│   └── <ticker>/yahoo.json
├── processed/                    ← 集計後の正規化データ
│   ├── <ticker>-summary.json
│   ├── comparison-matrix.csv     ← 7 社 × 19 KPI (BOM 付 UTF-8 / タスク仕様 "17" との差は known-issues.md §0)
│   ├── segment-mix-<ticker>.json (※ STUB。各社の実セグメント名のみ反映。値は未取得)
│   └── benchmarks.json           ← 5大商社平均 + 7社平均
└── refs/                         ← 補助レイヤー (Buffett 保有・コモディティ価格・政策保有推移)
```

## データソース

| ソース | 用途 | 認証 |
|--------|------|------|
| Yahoo Finance (`yahoo-finance2` npm) | 株価・PER/PBR/ROE/EBITDA/配当性向・現預金/有利子負債・市場時価総額 | 不要 |
| 既存 `data/edinet-financials.json` | (今回**未使用**) IFRS 適用商社では XBRL パーサー (J-GAAP 前提) が誤値を返すため。known-issues.md §4-4 参照 | EDINET API キー |
| EDINET API (有報 XBRL / 大量保有報告) | 政策保有 / 大量保有件数 / 自己株買い | **キー未取得** → known-issues.md §1 参照 |
| J-Quants API | 上場会社属性・財務時系列 | **キー未取得** → known-issues.md §1 参照 |

API キー未取得のため、本フェーズは **Yahoo Finance のみで取れる 9 KPI ÷ 19 KPI = 47.4% 充足** に留まる。
HTML 実装フェーズ着手前に森脇さんが両 API キーを発行 → `scripts/sogo-shosha/fetch_edinet_extra.py` (フェーズ2 で追加予定) を走らせて不足 KPI を補強する 2 段階方式。

## 開示粒度の差（重要）

| 項目 | 5大商社 | 双日 / 豊田通商 |
|------|---------|----------------|
| 資源 vs 非資源営業利益 | 公式分解あり (IR 説明会資料) | 双日: 部分開示 / 豊田通商: 自動車比率が支配的でカテゴリ自体が異なる |
| セグメント別 ROIC | 伊藤忠・三菱は IR で開示。三井・住友・丸紅は限定的 | 双日・豊田通商は非開示。連結 ROIC のみ |
| 海外売上高比率 | 全社で開示 | 双日・豊田通商も開示あり (連結ベース) |
| 政策保有株式の縮減進捗 | 5期前との比較を有報・統合報告書で開示 | 双日: 開示あり / 豊田通商: 自動車取引先株が中心で文脈が異なる |

詳細は `known-issues.md` の「開示構造の差」セクション参照。
